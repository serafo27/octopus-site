Every project in order. Everything under control.

Octopus is the work hub for your software projects. Tasks, terminals, AI sessions, docs and git live in one place, and Octopus keeps them up to date, so you always know where everything stands.

Tasks

Every task in its place.

Each project gets its own board, saved in its repository as plain Markdown. It stays in sync with your team through git, and updates by itself whenever a task changes, wherever it changed.

  • Add a task in one line: Fix the redirect !high #auth
  • One file per task, so no merge conflicts
  • Priorities, tags, checklists and filters

Delegation

Delegate a task without losing track of it.

Hand a task to your AI assistant in one click. Octopus briefs it with the task, its checklist and every doc it links to, then moves the task to In progress and on to Review when the work is done. The board always shows where things really stand.

  • Linked docs, pages and tasks go into the brief
  • A check command, like npm test, that moves the task when it passes
  • Every session and run, recorded on the task

Sessions

Every terminal accounted for.

All your sessions and shells, across every project, in one view. Each shows its state, so you always know what's running, what's finished and what's waiting for you.

  • Working
  • Waiting for you
  • Idle

Terminals open in Terminal, iTerm2, VS Code, Cursor, Warp or Ghostty show up too, filed under the right project.

Documentation

Docs that stay next to the work.

The Markdown in your repository, one tab away from tasks and terminals. Link a doc to a task and it's always at hand, for you and for the AI working on it. With Mido installed you get its full editor, with diagrams, math and comments.

  • Read, edit or both side by side
  • Rename a document and every link to it follows

Git and review

See every change before it ships.

Every changed file, side by side, then stage, commit and push from the same window. The review page remembers which files you've already read, so nothing slips through.

  • Commit, push, pull, merge and resolve conflicts
  • Branches and history at a glance

Notebooks

Specs, notes and plans, connected to the work.

Write the spec where the tasks are. A to-do on a page is a real task on the board, kept in sync both ways, and databases organize everything else with table, board, list and calendar views.

  • Slash commands, code blocks, callouts and links
  • Relations, rollups and formulas in databases

Priorities

One list of what's next, across every project.

Every open task from every project, sorted by priority, with what's running on top. Start your day here and decide what comes next. Tasks that belong to no project have a place here too.

Small things that keep it all in order.

Search everything
Find any project, task, page, document or session from one box: ⌘⇧F.
Work and personal, kept apart
Use a different AI account per project. Every session starts and resumes in the right one by itself.
Pick up where you left off
Your sessions come back after a restart, conversations included.
Terminals in their own window
Pop a session out to its own window. Close the window and it goes back where it was.
Links between everything
Tasks, pages and docs link to each other with plain Markdown, and each one lists what links back to it.
Themes
Dark and Light Modern, GitHub, Dracula, Nord and Solarized, or follow macOS.

Extensions

Bring the rest of your tools into the hub.

Need your logs, an internal API or a standup summary next to your tasks? Describe it, and the AI builds it as a new section of Octopus while you watch it take shape.

  1. Describe it

    Say what you need. The AI writes it next to a live preview, and you refine it by asking.

  2. Approve what it can reach

    An extension only reaches the sites, tasks or docs it asks for, and only after you say yes.

  3. Share with your team

    Publish it to your team's marketplace, any git repository. Teammates install it in one click and get every update.

macOS says Octopus can't be opened

Until builds are notarized by Apple, macOS asks the first time. Open System Settings › Privacy & Security and choose Open Anyway, or run:

xattr -dr com.apple.quarantine /Applications/Octopus.app
